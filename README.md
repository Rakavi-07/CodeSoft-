# CodeSoft-
Completed a Java Programming internship at CodeSoft where I developed multiple console-based applications to strengthen my understanding of core Java concepts, object-oriented programming, user input handling, control structures, and file management. Each task focused on solving real-world problems through structured program design.

🔹 TASK 1 – Number Game

Description:
Developed a number guessing game in Java where the system generates a random number and the user attempts to guess it within a limited number of attempts. The program provides feedback for each guess and tracks the number of tries, helping improve logical thinking, loop control, and condition handling.

🔹 TASK 2 – Student Grade Calculator

Description:
Created a student grade calculator in Java that accepts marks for multiple subjects, calculates the total, average percentage, and assigns grades based on predefined criteria. The application includes input validation and displays clear academic performance results, reinforcing arithmetic operations and conditional logic.

🔹 TASK 3 – ATM Interface

Description:
Designed a console-based ATM application using Java that simulates basic banking operations such as withdrawing, depositing, and checking account balance. Implemented separate classes for ATM and BankAccount to follow object-oriented principles, along with input validation and transaction status messages.

🔹 TASK 4 – Currency Converter

Description:
Built a currency converter application in Java that allows users to select base and target currencies, enter an amount, and view the converted value using exchange rates. The program emphasizes accurate calculations, input validation, and user-friendly output formatting.

🔹 TASK 5 – Student Management System

Description:
Developed a Student Management System in Java to manage student records efficiently. The system supports adding, editing, deleting, searching, and displaying student information with file-based data storage for persistence. This task strengthened concepts of collections, file handling, and object-oriented programming.
